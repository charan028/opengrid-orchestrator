      Actions

      Every action is two steps: propose, then confirm the exact summary the API returns. The guardian checks and signs every command.

      Command one hub

      Pick a hub (its bank fills in) or a whole bank, set the power and how long it holds. The engine ramps to it at the hub's ramp limit.

          min

          Setpoint sign: + charges, − discharges. Pick a hub to see its limit.

          Command selection

          Override what the selected hubs are doing now. A second acknowledgement is needed if any serve a customer or are faulted.
