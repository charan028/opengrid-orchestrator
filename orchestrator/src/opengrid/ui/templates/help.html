About this reference

Generated when this page is rendered from the routes this process actually serves ({{ api_endpoint_count }} endpoints under /og/api), so it always matches the running release. The role column is read from each endpoint's own authorisation dependency: viewer (any mapped identity), operator (write actions; the API re-checks it even when the console already did), customer key (the customer API, mounted only when [api.customer_api].enabled is on), local probe (health probes from the host itself). Inbound endpoints are called by the console, operators, viewers and customers; /og/api/stream/* are outbound server-sent event streams that push live updates to the console. Outbound integrations to devices and markets (signed MQTT commands, firmware commands, the disabled ERCOT MMS adapter) are described under Integrations and MQTT topics.
